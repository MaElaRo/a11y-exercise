# Accessibility interview exercise

This page is a hands-on exercise for accessibility design interviews. It is not a real product.

The page contains **deliberate accessibility issues**. Candidates audit it with a screen reader during the interview and talk through how they would fix and redesign the problem areas. Please don't report these issues or open pull requests to fix them.

The brand "Werkstoff" and all lesson content are fictional.

Live page: https://maelaro.github.io/a11y-exercise/
